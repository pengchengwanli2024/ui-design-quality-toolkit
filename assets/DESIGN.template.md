# 项目设计规范

## 范围与来源

- 适用页面、用户与核心任务：
- 已确认方向与品牌资产：
- 参考 URL / 文件 / commit / 核验日期：
- 实际观察的视口、主题与交互状态：
- 第三方分析、推断和未知项：

## 视觉与布局

- 信息层级、主要操作与内容密度：
- 页面外壳、栅格、对齐与留白：
- 字体层级、中文换行与数字排版：
- 表面、边框、圆角和层次：

## 响应式与交互

- 窄屏布局、导航及表格策略：
